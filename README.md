# eCommerce Website with Admin Panel

This **eCommerce website** is developed using **React.js** for the frontend and **Tailwind CSS** for styling. It features an **admin panel** that allows admins to perform **CRUD (Create, Read, Update, Delete)** operations on products, simulating the functionality of a live eCommerce store.

### Key Features:
- **Dynamic Product Listings**: Users can browse through products with categories and detailed views.
- **Admin Panel**: Fully functional admin interface for managing products (add, update, delete).
- **Responsive Design**: Built with a mobile-first approach using **Tailwind CSS**, ensuring a seamless experience across all devices.
- **API Simulation**: Fetches and manages product data using a **dummy API** to simulate real-time data interactions.
- Cart functionality

### Technologies Used:
- **React.js**: For building the interactive UI and managing application state.
- **Tailwind CSS**: For styling and responsive layout.
- **JavaScript (ES6+)**: For handling dynamic functionality.
